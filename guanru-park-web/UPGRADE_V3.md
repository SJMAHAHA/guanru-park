# Guanru Park 3.0

保留 2.0 建筑基线，完成现代室内装修、厨房设备与实时材质升级。可编辑模型和完整制作脚本位于 `../guanru park/展示模型_3.0`；2.0 原交付保持独立。

- B1、1F、2F、3F 共 70 个空间记录；包括主要房间与交通区域。逐间清单随 `/assets-v3/rooms.json` 提供。
- 移除非厨房柜体；卧室改开放小桌，衣帽间改挂衣杆和坐凳，卫生间采用悬挑台盆，电视有墙面安装支架。
- 中厨、西厨包含整合橱柜、冰箱、烤箱、蒸箱、台下洗碗机、台下盆、灶具及排烟设备。
- 2K PBR 贴图，高画质使用接触阴影、SMAA、4096 阴影和实际烘焙的楼层间接光；标准档使用 1K 材质、较低像素比例和 2048 阴影。
- 玻璃与水使用物理透射材质。楼层、剖切、展开、家具显隐、房间聚焦和日夜功能保留，补充中厨、主卫、餐厅、办公室及屋顶近景。

验证入口：`node --experimental-strip-types scripts/verify-v3.mjs`。该检查实际解码导出几何，验证楼层分组、材质 UV、烘焙 UV2、尺寸、相机目标、家具显隐和反复分层复位。浏览器实测见原生交付目录的升级说明与 `qa` 文件夹。

主卫近景增加有范围限制的实时平面镜。其他材质反射使用环境贴图和屏幕中的透射信息；不是路径追踪。间接光烘焙覆盖主要楼层地面，剖切、展开或隐藏家具时停用。标准档首次仍需载入共享模型和高分辨率源材质，切换后使用 1K 变体；它主要降低持续渲染开销。建筑尺寸来自参考图重建，作为展示模型使用。
