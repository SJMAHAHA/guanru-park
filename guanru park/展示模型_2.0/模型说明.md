# Guanru Park 2.0 · 精细建筑展示模型

## 交付文件

- `Guanru_Park_2.0.blend`：可编辑 Blender 工程，米制单位；Blender 5.1.2 建立。
- `renders/`：正式鸟瞰、两向外观、泳池近景、主客厅、主卧、西厨、傍晚灯光，以及 B1 / 1F / 2F / 3F 家具平面和剖切轴测，共 16 张 PNG。外观和室内为 2400 × 1660，分层图为 2000 × 2000；Cycles 96 采样并降噪。
- `build_villa.py`、`details_v2.py`：基础建模与 2.0 精细构件脚本，均内嵌于工程 Text 数据块。
- `textures/`、`make_textures.py`：21 张自制 PBR 贴图与生成脚本；全部贴图另已打包在 Blender 工程中，无联网依赖。
- `web_export/export_web.py`：按楼层与用途导出网页模型，网页源码中的脚本负责压缩及验证。
- `render_views.py`：独立重渲染脚本，可选择单个视角。
- `inspect_villa.py`、`qa/validation.json`：重新打开工程后的检查脚本与结果。
- `room_schedule.json`：62 个主要功能区域的名称、楼层与参考坐标；包括共享功能空间，不是建筑面积统计表。

## 查看与编辑

打开工程即为整体日景。顶部 Scene 下拉中可直接切换 `10 · B1 家具平面 / isolated`、`10 · 1F 家具平面 / isolated`、`10 · 2F 家具平面 / isolated`、`10 · 3F 家具平面 / isolated`；另有 `20 · 完整建筑 | TWILIGHT` 傍晚场景。六个场景共享模型对象，编辑会同步；灯光另行配置。

主场景按 B1、1F、2F、3F 和 Roof 分组，每层再分 Structure、Windows、Furniture、Pools、Details、Ceilings、Labels。Roof 为顶层小体量的屋盖；3F 含二层上方的大屋面和局部房间。隐藏 Roof 可看三层局部房间；再隐藏 3F 可看二层；依次隐藏上层可继续查看内部。各剖切相机保存在 Cameras 分组，选为活动相机即可重渲染。

同尺寸重复构件与家具尽量共享网格数据；如只想修改某一件的网格，可先将该对象的数据设为独立副本。

参考平面以同一尺度保存为图像 Empty，位于默认隐藏的 References 分组。原始图像已打包进工程。可临时显示该组做平面对照。房间名称保存在地面对象及 Labels 对象中，Labels 默认不参与效果图渲染。

## 推定尺度与标高

全部平面共用坐标。以参考截图显示为 2048 × 1152 时约 **18.75 像素 / 米**建立几何；原图为 3840 × 2160，等效约 35.16 原始像素 / 米。以家庭客厅、主卧、餐厅、乒乓球室等面积交叉校准，面积仅辅助判断。图像墙线、面积标注与透视存在误差，因此这不是实测尺寸图。

- 基座外包约 **46.7 × 50.4 米**。西、南为直线边，东北为局部弧边，未改成整圆或椭圆。
- B1 / 1F / 2F / 3F 完成面暂定 **0.00 / 3.15 / 6.30 / 9.45 米**；顶层屋面约 12.60 米。
- 结构楼板约 0.27–0.28 米，放在楼层标高以下；一般层间可用高度约 2.88 米，不再把楼板厚度叠加进层高。局部梁、灯具、收口略降低局部高度。
- 外围墙约 0.26 米，主要内墙约 0.18 米；门洞一般宽 0.90–1.40 米、高 2.35 米。采用真实洞口、框体与部分开启门扇。
- 屋顶小体量按完整外观与三层剖切交叉推定，约 **15.6 × 7.7 米**，只占局部屋顶；未扩展成完整第三层。

## 保留的假设与可调整区域

1. B1 用模型基准面 0 米表示，环境地面低于其完成面，保留可见基座与窗洞；并未用新增地形掩埋。
2. 二层主客厅上方约 75.74㎡标注区按剖切图处理为挑空，连接区另外两处灰色区域保留开口；西侧开口保留简化状态，东侧用于竖向交通。主客厅形成上下贯通空间。两处朝向挑空的疑似门符号简化为固定观察窗，避免开向挑空，保留为可调整假设。
3. 西厨南端、西南楼梯间和东侧楼梯间的开口按共有墙线对齐；主交通在较大洞口内使用双跑折返楼梯：18 级、约 175 毫米踏高、280 毫米踏面、约 1.40 米单跑宽及 1.0 米中间平台。东侧约 6.62㎡的小洞保留为服务竖井，不强行指定梯型。截图未给出具体梯型，踏步与扶手为展示补充。
4. 半环形车辆坡道内 / 外半径约 1.97 / 5.76 米，净带宽约 3.79 米，连续坡面连接 B1 与 1F。按 3.15 米高差计算，中线平均坡度约 **26%**；这是保留参考图几何所得，未声称满足车辆通行或施工规范。后续若取得原始车道尺寸，应优先复核并调整。
5. 原图 B1 中标注“泳池蓄水池”的弧边区域保留为空间与上层泳池池体的关系，不将它当成额外居住房间。
6. 主卧泳池暂按 0.60 米水深的浅水休闲池示意，使下方户外客餐区池底最低处保留约 2.28 米净空；池沿标高与平面范围保持原推定关系。参考未提供池体剖面，后续有尺寸时应重新核定池深与结构。
7. 3F 缺少完整平面，用外观体量控制范围，内部采用少量房间与楼梯的简洁布置。三层精确分隔、局部洞口含义与所有未给尺寸的窗分格仍属推定。
8. 该成果是依据截图重建的建筑展示模型，并非原始 CAD / BIM 的精确复原。墙线与功能区域优先保持对应，局部门扇方向、楼梯形式、结构支撑及设备外形作了可编辑的简化。

## 展示补充设计

暖白哑光墙面、浅色石材、木地板、深灰铝框、清透玻璃、蓝绿色水体、米灰家具均为补充选择，不代表原方案已指定这些材料。玻璃有厚度及透射，泳池包含池底、池壁、池沿、水面与简化入水踏步。硬构件有小倒角，软家具为圆润独立构件。

家具按正常尺寸放置：双人床约 1.9 × 2.06 米，餐椅约 0.55 米宽，主沙发约 3.25 米长；大型房间留有通道，不按房间面积等比例放大家具。次卧与员工房使用复用家具。康体设备、车、酒架和设备柜采用足以识别用途的几何。

环境为低地面、简洁入口铺装、少量盆栽与灯具；日景优先，不添加复杂园林。2.0 使用 UV 与实体尺寸匹配的木纹、石材、织物、灰泥、金属及水面 PBR 贴图。21 张颜色、粗糙度、法线贴图已打包进工程，与三张平面参考合计 24 张内置图片。

## 重建与渲染

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python build_villa.py
/Applications/Blender.app/Contents/MacOS/Blender --background Guanru_Park_2.0.blend --python render_views.py -- all
```

第二条命令可将 `all` 换为 `01` 至 `12` 中的编号；05 / 06 / 07 / 12 分别生成 B1 / 1F / 2F / 3F 平面与轴测，10 为西厨，11 为傍晚。可追加 `preview` 输出低分辨率检查图。

生成脚本只写本交付目录内的指定成果文件，不覆盖项目目录中的其他 Blender 工程。完整交付包另含 `references/` 中的全部 13 张原始参考图；重建脚本会从该文件夹或上级项目目录寻找平面参考。即使未携带参考图，已记录的几何坐标仍可用于重建，缺少的参考 Empty 会跳过。

## 2.0 的精细度升级

- 建筑收口：窗框压条与密封线、门把手、玻璃栏杆夹件、踢脚与顶棚收口、屋面压顶和排水口、铺地与池沿分缝。
- 家具软装：沙发分体坐背垫与包边，13 张床的垂坠被褥、毯子与枕边线，软包床头、空心灯罩和褶皱窗帘。
- 厨卫与配件：16 个空心台盆、浴缸内腔、龙头与淋浴件、灶具标记、烤箱旋钮、吧椅脚踏、空心杯盘、植物枝叶与花盆。
- 材质与光照：微表面 PBR 纹理、金属反射、柔和水波，室内补光、吊灯与灯槽，以及独立傍晚场景。

主要对象由 4,994 个增加至 8,654 个，材质从 25 种增至 36 种。升级沿用 1.0 的尺度假设；五个关键基座、楼板与屋顶网格的顶点及面拓扑经对照保持一致，62 个功能区域不变。新增细节属于展示补充设计。
