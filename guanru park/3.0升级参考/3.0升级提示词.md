# Guanru Park 3.0 升级提示词

## 2. 统一为现代风格，完成真正的室内装修

采用简洁、温暖的现代设计：暖白、浅灰、自然木色为主，辅以少量深灰金属、石材和玻璃。各层风格统一，不做繁复古典线脚、大面积金色装饰或过度花哨的背景墙。

不能只给白墙换颜色或只增加家具。所有可进入的主要房间应有完整的地面、墙面、顶面、门套、踢脚或收口、灯具和窗帘设计。公共空间可采用大规格石材或瓷砖；卧室采用木地板、适量床头软包和地毯；厨卫采用合适的地面、墙面、挡水及玻璃隔断。吊顶与灯槽保持简洁，并兼顾层高。

补充嵌入式筒灯、线性灯、局部吊灯和壁灯，合理安排开关、插座与空调风口。灯具应有真实几何和照明效果，不能仅靠发光贴图表现。材质应具有自然的粗糙度、纹理尺度和细微表面变化。

主客厅、西厨、餐厅、主卧与主卫重点深化；其他卧室、客房、办公室及娱乐空间完成与用途相符的基本装修。不能只做好一两个拍照角落，而让其他主要房间维持空白白模。

## 3. 厨房以外的房间不设置柜体

本次按以下范围执行：厨房橱柜是明确例外；其他房间不设置衣柜、床头柜、斗柜、电视柜、书柜、餐边柜、展示柜、储物柜或浴室柜，也不通过嵌入墙面的方式变相增加这些柜体。

- 卧室：保留床、无抽屉的开放床边小桌、座椅、灯具、地毯和必要书桌。
- 客厅：采用壁挂电视或投影幕，配合沙发、茶几和无储物柜体的边桌。
- 办公室：采用无柜体书桌和办公椅，避免整面储物墙。
- 卫浴：使用独立或悬挑台盆台面，不设置台盆下柜体。
- 衣帽间：保留房间及用途，以简洁开放挂衣杆、独立衣架和坐凳表达，不增加封闭衣柜或成排柜式格架。
- 酒窖等特殊功能空间：需要时使用开放式专用酒架，不添加装饰柜或储物柜。

检查 2.0 已有柜体，将不符合要求的物件移除或替换，并同步更新网页资产；不能只在某个视角隐藏它们。避免把墙板、门、设备外壳等误判为柜子。

## 4. 按房间用途补全家具、电器和设备

先建立房间清单，逐间核对已有、缺失和需替换物件。补齐实际用途需要的家具与电器，数量适度，统一尺度和风格。

- 客厅、起居室：沙发、单椅、茶几、开放边桌、灯具、电视或投影及合理音响。
- 餐厅：完整餐桌椅、吊灯和少量餐具；卧室：床架、床垫、被褥、枕头、窗帘和床边开放小桌。
- 办公室：书桌、椅子、显示器和台灯；洗衣房：洗衣机、烘干机、无柜体操作台和洗衣篮。
- 卫浴：台盆、龙头、镜面、马桶、淋浴、必要浴缸及毛巾杆等配件。
- 健身、影音、乒乓球、保龄球、模拟高尔夫等房间：配置能明确体现功能的器材、座椅、屏幕或设备。
- 泳池、露台和户外客餐区：补齐必要的躺椅、户外桌椅和适量植物。

家具与电器需要经得起正常室内距离查看：家具具有腿、框架、坐垫或软包等结构；电器具有门缝、面板、把手或操作区等识别细节，不能全部用简单方块代替。无需制作内部机械结构。

所有物件应落地或有明确安装支撑，保持门洞、楼梯和通道通畅，避免穿墙、悬空、重叠和夸张尺寸。

## 5. 厨房橱柜与相应电器采用内嵌一体化设计

中厨、西厨根据各自空间布置成完整现代厨房。橱柜沿墙体凹位或设计好的整合墙面嵌入，与墙面、收口和台面协调，避免把一排独立箱体简单贴墙摆放。合理保留操作台和需要的岛台，不侵占窗洞和通道，不为了内嵌而任意破坏主要墙体。

- 冰箱采用嵌入式整合方案；烤箱、蒸箱或微波设备嵌入相应模块；洗碗机安装在台面下。
- 灶具嵌入台面，水槽采用台下式或齐平式；抽油烟设备按厨房形式整合，并表现合理的排烟路径。
- 柜门和电器面板有统一分缝及必要收口，配色与整体现代风格一致。
- 保留正常开门、操作和散热空间；内嵌不是让电器穿进墙体，也不是把电器面板贴在封死的柜门上。
- 清洗、备餐和烹饪区有合理关系；厨房电器按使用需要配置，避免无意义重复堆放。
- 在浏览器近景中，能够看清柜门分缝、台面厚度、水槽、龙头、灶具和主要电器面板。

## 6. 显著提升浏览器实时预览质量

同步升级网页实际加载的三维模型、材质、灯光和渲染设置。不能仅替换效果图、放大画布或修改界面样式来宣称预览升级。

默认面向性能较好的桌面设备提供高画质，可以增加合理的几何细节、贴图分辨率、阴影和反射成本。重点改善家具轮廓、软包曲面、门窗厚度、厨电细节和室内近景质感。不要为了增加设备负担而无意义细分所有模型。

- 主要近景材质优先使用清晰的 2K 贴图，确有可见收益的重点表面可用 4K；小物件复用合适资源，不统一堆高分辨率。
- 改善抗锯齿、纹理过滤、阴影精度、接触阴影和间接光表现，避免明显锯齿、闪烁、阴影漏光及室内死黑。
- 检查 2.0 网页导出中的玻璃和水材质简化处理。根据当前浏览器渲染能力，恢复或重建合理的反射、透射、透明排序和水面表现，避免玻璃发黑、像蓝色塑料，或透过窗户看不清室内。
- 对 Blender 中无法直接导出的复杂材质，转换为网页可用材质或适当烘焙，再在浏览器内核对。不要假定离线渲染的效果会自动完整保留。
- 在现有预览上保留楼层切换、屋顶显隐、剖切、分层展开、家具显隐、房间聚焦及日景／傍晚等已有功能；补充或完善主要室内空间的平视预设和近距离查看。
- 提供高画质和标准画质选择，桌面默认高画质。保留资源复用、合理剔除和加载反馈，让用户知道模型正在加载。
- 在可用测试设备上记录浏览器、视口、画质档位、加载耗时和典型视角帧率。将稳定交互作为目标，按实测报告表现，不承诺未经测试的固定帧率。

## 7. 检查和交付

分别在 Blender 和实际浏览器中检查外观、主客厅、厨房、卧室、卫浴及各层剖切。确认房间具备装修、柜体限制落实、厨房嵌入式设备完整，网页没有遗漏新模型、贴图或家具，也没有加载失败、透明排序错误及明显穿模。

使用与 2.0 尽量一致的机位和画幅输出对比，至少覆盖整体鸟瞰、主客厅、西厨、主卧和一张楼层剖切。浏览器截图必须来自实际预览，不能用离线渲染图冒充实时画面。

交付可编辑的 3.0 `.blend`、更新后的网页源码与模型资源、可实际查看的预览入口、代表性效果图和浏览器截图，以及简短升级说明。说明中列出各房间完成情况、柜体移除情况、厨房内嵌设备、实测性能及仍存在的限制。

最终效果应仍然明确对应原建筑，在此基础上形成统一现代风格和完整室内装修；厨房以外房间无柜体，家具电器与空间用途匹配，厨房具备一体化内嵌设计，并且浏览器中靠近查看时能看到相比 2.0 明显增加的细节和更好的材质光照。
